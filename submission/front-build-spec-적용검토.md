# front-build-spec 적용 검토 — 규정다름 MABC 2026 결선

## 서비스 프론트엔드 현황

규정다름 프론트엔드 (`service/public/index.html`):

- 단일 페이지 HTML + CSS, 바닐라 JS
- 입력: 구판 텍스트 textarea + 신판 텍스트 textarea + 파일 첨부 (txt/csv/xlsx/docx)
- 출력: 신구 조문 대조표(테이블), D-day 표
- 디자인: 미니멀 카드 UI, 파란 accent, 다크 모드 대응 CSS 변수
- 반응형: 모바일 대응 있음

## front-build-spec 관점 검토

- **의도**: 행정규칙 신구 대조 + D-day 계산 결과를 명확하게 보여주는 것
- **단일 주요 상호작용**: 텍스트 입력/파일 선택 → "대조 실행" 버튼 → 결과 표시
- **팔레트/폰트**: 시스템 폰트 사용 (웹 안전 폰트), CSS 변수 기반 테마
- **배포 형태**: 단일 HTML 파일 + API 호출 (Vercel 정적 호스팅 + Python 서버리스)
- **저하 경로**: JS 비활성 시 폼 제출 불가 (이는 현실적 제한)

## 개선 여지 (제출 마감 후)

- 더 정교한 타이포그래피, 다크 모드 토글, 결과 내보내기(PDF/이미지)
- 파일 드래그앤드롭 시각적 피드백 개선
- 입력 예시/가이드 강화

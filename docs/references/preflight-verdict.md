## 5. 인터페이스 판단 (파일 첨부 vs 붙여넣기)

- MVP(현재): 텍스트 붙여넣기. 이 방식은 즉시성·단순성·스크립트 직접 연결 측면에서 유리.
- 파일 첨부 방식은 사용자 요구("파일을 첨부해서 바로 사용")에 부합할 수 있으나, MVP 범위를 벗어나고 구현 리스크 증가.
- 판단: 제출용 MVP는 붙여넣기 유지 + "파일 업로드 지원 검토"를 향후 발전 방향(발표자료 07)으로 명시하는 전략이 안전.

## 6. ICP·VP (제출용)

- ICP 예: 금융위원회 보험과, 개인정보보호위원회 개인정보보호정책과, 조달청 규제개혁법무담당관 (이미 포스터에 반영).
- VP: "공무원이 개정 통지서를 받았을 때, 두 문서를 출력해 눈으로 비교하던 작업을 텍스트 붙여넣기만으로 수초 내에 조문 대조 + 시행 D-day까지 파악" → 기존 불편의 정확한 지점을 찌르는 문장.
- 근거: law.go.kr의 법령 비교 기능이 있어도 비개발자가 즉시 대조+D-day까지 한 화면에서 보는 방식은 아님(실제 확인 기반).

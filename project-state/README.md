# 프로젝트 상태 폴더 — 규정다름 (MABC 2026 결선)

이 폴더는 세션 사이에 사라지는 맥락을 보존하는 곳이다.  
새 세션은 아래 프롬프트를 복붙하고, 이 폴더 안의 파일들만 먼저 읽는다.

## 이 폴더의 용도

- **HANDOFF.md**: 직전 세션까지의 진행, 결정, 남은 작업, 다음 액션
- **MEMORY.md**: 프로젝트가 계속 기억해야 할 장기 사실(모델 규약, 대회규칙, 파일 위치 등)
- **STATE.md**: 현재 작업 상태 + 활성 todo + 최신 진행
- **session-start-prompt.md**: 새 세션 진입 시 복붙용 프롬프트
- **session-close-instructions.md**: 세션 종료 시 정리하는 방법

## 규칙

- 세션이 끝나면 HANDOFF/STATE/MEMORY를 갱신한다.
- 새 세션은 repo 전체 스캔부터 하지 말고, 이 폴더의 프롬프트와 상태 파일부터 읽는다.
- 이 폴더의 내용은 Solar Pro 4만 사용해서 갱신한다.

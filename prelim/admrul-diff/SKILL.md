# admrul-diff

행정규칙/지침 신·구 조문 대조 및 시행 D-day 계산기.

- 입력: 구판(행정규칙/지침) 텍스트, 신판(행정규칙/지침) 텍스트
- 출력: diff 항목별(added/modified/deleted) 신구 대조표 + 부칙 시행일 기반 D-day / 시행상태

## 언제 사용

- 동일한 행정규칙/지침의 구판과 신판(또는 개정 전후)을 대조 표로 정리할 때
- 신판에서 어떤 조문이 신설·변경·삭제되었는지, 부칙 시행일은 언제인지, 오늘 기준 시행일 상태(D-n / 오늘 시행 / 시행중 / 시행일 미검출)를 함께 산출할 때

## 입력

- 구판 파일 1개, 신판 파일 1개 (텍스트)
- 파일을 첨부하지 않으면 스킬에 동봉된 샘플(`admrul_sample_old.txt`, `admrul_sample_new.txt`)로 데모 모드로 자동 실행된다.

## 🚨 강행 규칙 (반드시 지킨다)

- 신·구 조문 비교, diff 판정(added/modified/deleted), 부칙 시행일 파싱, 오늘 날짜 기준 D-day 계산은 **100% `scripts/admrul_diff.py` 파이썬 스크립트에서만** 수행한다.
- LLM(모델)은 반드시 **`python scripts/admrul_diff.py [구판] [신판]`을 실행**하고, 그 출력이 순수 JSON 하나이므로 **그 JSON 결과만 최종 마크다운 표로 옮겨 렌더링**한다.
- 모델은 **자체 임의 판정·추정·계산을 절대 하지 않는다**. 조문 누락·신설·변경·삭제를 눈으로 보고 판단하지 말 것. 시행일/D-day도 계산·추정하지 말 것.
- 스크립트 실행이 실패하거나 에러가 나면, 모델의 임의 보정 없이 스크립트 출력 그대로 에러를 전달한다.
- 위 규칙은 권고가 아니라 이 스킬의 핵심 강행 규칙이다. 위반 시 잘못된 결과가 나온다.

## 실행

```bash
# 구판/신판 파일 지정 (보통은 경로와 함께)
python scripts/admrul_diff.py 구판.txt 신판.txt

# 파일 미지정 시 데모 모드 (동봉 샘플 사용)
python scripts/admrul_diff.py
```

## 출력 (JSON 스키마)

스크립트는 표준 출력으로 JSON 하나를 출력한다.

### 정상 케이스

```json
{
  "diff": [
    {
      "article_number": "2",
      "article_title": "운영시간",
      "judgment": "modified",
      "old_content": "자료실의 운영시간은 오전 9시부터 오후 6시까지로 한다. 다만, 관장이 필요하다고 인정하는 경우 운영시간을 조정할 수 있다.",
      "new_content": "자료실의 운영시간은 오전 9시부터 오후 9시까지로 한다. 다만, 관장이 필요하다고 인정하는 경우 운영시간을 조정할 수 있다."
    },
    {
      "article_number": "4",
      "article_title": "자료 대출",
      "judgment": "modified",
      "old_content": "이용자는 1인당 5권의 자료를 14일간 대출할 수 있다.",
      "new_content": "이용자는 1인당 7권의 자료를 21일간 대출할 수 있다."
    },
    {
      "article_number": "6",
      "article_title": "디지털 자료실 운영",
      "judgment": "added",
      "old_content": "",
      "new_content": "디지털 자료실은 회원증을 발급받은 이용자에 한하여 1일 2시간 이내로 이용할 수 있다."
    },
    {
      "article_number": "5",
      "article_title": "음식물 반입 금지",
      "judgment": "deleted",
      "old_content": "자료실 내에는 음료를 포함한 일체의 음식물을 반입할 수 없다.",
      "new_content": ""
    }
  ],
  "enactment": {
    "old_date": "2026-03-01",
    "new_date": "2026-09-15",
    "reference_date": "2026-08-30",
    "new_d_day_status": "D-16",
    "old_d_day_status": "시행중"
  }
}
```

### 필드 설명

**diff 배열 (항목별)**
- `article_number`: 조문 번호 (문자열, 예: "2", "4의2" 등 가지조문 포함)
- `article_title`: 조문 제목 (없으면 조문 번호로 대체)
- `judgment`: `added` / `modified` / `deleted` 만 사용
- `old_content`: 구판 조문 내용 (added 면 빈 문자열)
- `new_content`: 신판 조문 내용 (deleted 면 빈 문자열)

**enactment (시행일 정보)**
- `old_date`: 구판 시행일 (YYYY-MM-DD, 미검출 시 null)
- `new_date`: 신판 시행일 (YYYY-MM-DD, 미검출 시 null)
- `reference_date`: 기준일자 (KST 오늘, YYYY-MM-DD)
- `new_d_day_status`: 신판 시행일 상태
- `old_d_day_status`: 구판 시행일 상태

### D-day 판정 상태 (3상태 + 예외)

- 시행일이 오늘보다 미래: `D-n` (예: `D-16`). 수식 기호 없이 일반 텍스트.
- 시행일이 오늘: `오늘 시행`
- 시행일이 오늘보다 과거: `시행중`
- 부칙에서 시행일 문구를 찾지 못한 경우: `시행일 미검출`

### 오류 케이스

규격 외 입력 등 예외 상황에서는 JSON 하나로 에러 응답을 반환한다.

```json
{
  "error": true,
  "message": "구판에서 조문 패턴(제N조)을 찾을 수 없습니다. 행정규칙/지침 형식이 아닌 것으로 보입니다."
}
```

에러 시 종료 코드: 일반 검증 실패는 1, 데모 파일 IO 실패는 2. 모델은 종료 코드까지 임의로 조정하지 않고 스크립트 출력 그대로 처리한다.

## 렌더링 (모델이 한다)

1. `python scripts/admrul_diff.py` 실행 → 표준 출력 JSON 획득
2. JSON이 `error: true`면 에러 메시지를 그대로 사용자에게 전달 (임의 재구성 금지)
3. 정상이면 아래 2개 표로 렌더링한다.

### 표 렌더링 시 마크다운 셀 줄바꿈 규칙

- 표 셀 안에 여러 줄(항/호)의 조문 본문을 넣을 때, `<br>` 같은 HTML 태그를 절대 사용하지 말 것.
- 줄바꿈 대신 슬래시(` / `) 기호나 공백으로 자연스럽게 이어서 한 줄 마크다운 텍스트로 깔끔하게 표기할 것.

### 표 1 — 신·구 조문 대조표 (diff)

| 구분 | 조문 | 구판 내용 | 신판 내용 |
|------|------|-----------|-----------|
| 신설 | 제6조(디지털 자료실 운영) | (신설) | 디지털 자료실은 회원증을 발급받은 이용자에 한하여 1일 2시간 이내로 이용할 수 있다. |
| 변경 | 제2조(운영시간) | 자료실의 운영시간은 오전 9시부터 오후 6시까지로 한다… | 자료실의 운영시간은 오전 9시부터 오후 9시까지로 한다… |
| 변경 | 제4조(자료 대출) | 이용자는 1인당 5권의 자료를 14일간 대출할 수 있다. | 이용자는 1인당 7권의 자료를 21일간 대출할 수 있다. |
| 삭제 | 제5조(음식물 반입 금지) | 자료실 내에는 음료를 포함한 일체의 음식물을 반입할 수 없다. | (삭제) |

- `judgment` 기준: added → 신설, modified → 변경, deleted → 삭제
- 변경 없는 조문은 표에 넣지 않는다.

### 표 2 — 시행 D-day

| 항목 | 구판 | 신판 |
|------|------|------|
| 시행일 | 2026-03-01 | 2026-09-15 |
| 기준일자 | 2026-08-30 | 2026-08-30 |
| 시행상태 | 시행중 | D-16 |

- `new_d_day_status` / `old_d_day_status` 값을 그대로 표 칸에 넣는다 (계산 금지).
- 시행일이 `null`이면 해당 칸에 "시행일 미검출"이라고 적는다 (값은 변경하지 말 것).

## 예외 처리

- 구판/신판 중 하나가 비어 있거나 제N조 패턴이 없으면 구조화된 에러 JSON + 비정상 종료 코드를 반환한다.
- 파일을 찾을 수 없으면 에러 JSON + 종료 코드 2.
- 모델은 위 경우에도 임의 정상 표를 만들지 않고 오류 메시지를 그대로 전달한다.

## 동봉 샘플 (데모용)

- `samples/admrul_sample_old.txt`
- `samples/admrul_sample_new.txt`

이 파일들은 스킬 요구 시 첨부 파일이 없을 때 데모 모드에서 자동 사용된다.
